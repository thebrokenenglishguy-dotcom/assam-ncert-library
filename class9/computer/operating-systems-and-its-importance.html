4. Short Answer Questions

1. What is an Operating System?
An Operating System (OS) is system software that manages computer hardware and software resources and provides an interface between the user and the computer.
2. Mention the names of any two commonly used operating system.
Windows and Linux.
3. When was the first version of Apple iOS released?
The first version of Apple's iPhone operating system, later known as iOS, was released in 2007.
4. What do you mean by multitasking?
Multitasking is the ability of an operating system to run or manage more than one task or program at the same time.
5. What is real-time operating system?
A real-time operating system (RTOS) is an operating system that processes tasks and produces responses within a specified time limit.
6. What is time sharing and distributive operating system?
Time-sharing OS: It allows many users or programs to share CPU time by giving each a small time slice. Distributed OS: It manages a group of connected computers and makes their resources work together as a coordinated system.

5. Long Answer Questions

1. Explain any two functions of an Operating System.
Process management: The OS manages running programs and allocates CPU time to them. Memory management: The OS allocates and frees memory for programs and keeps track of memory use.
2. Explain any two operating system used in mobile phones.
Android: A mobile operating system developed by Google and based on the Linux kernel. iOS: Apple's mobile operating system used on iPhone devices.
3. Write a short note on Windows operating system.
Windows is a proprietary operating system developed by Microsoft. It provides a graphical user interface and manages hardware, files, memory, processes and applications. Windows is widely used on personal computers.
4. Write a note on the operating systems created by Apple.
Apple has developed operating systems for different devices. macOS is used on Mac computers, while iOS is used on iPhones. Apple also develops operating systems such as iPadOS, watchOS and tvOS for other devices.
5. What is BOSS?
BOSS stands for Bharat Operating System Solutions. It is an Indian Linux-based operating system developed by the Centre for Development of Advanced Computing (C-DAC).
6. Write a short note on Bill Gates.
Bill Gates is an American entrepreneur and computer programmer. He co-founded Microsoft with Paul Allen and played a major role in the development and popularisation of Microsoft software and Windows.
7. What is Interactive Operating System? Where is it used?
An interactive operating system allows users to interact directly with the computer and receive responses while working. It is used in personal computers, workstations and systems where users need immediate interaction with programs.
8. What are the two important features that must be taken care while maintaining a directory?
Two important features are proper organisation of files and directories and proper naming so that files can be identified, located and managed easily.
