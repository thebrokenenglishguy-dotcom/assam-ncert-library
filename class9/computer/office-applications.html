2. Multiple Choice Questions

1. Which extension is given to a document by default in MS-Word?

2. The status of your document like current page and number of pages are given by
b. Status bar
3. The general arrangement of the text in the document is
c. formatting
4. The ______ alignment makes sure that none of the edges of text appear ragged.
d. justify

c. leading
6. Header and Footer are inserted at the ______ of a document.

3. Answer the Following

1. How do you locate MS-Word 2007 on your computer system?
Click Start → All Programs → Microsoft Office → Microsoft Office Word 2007.
2. What is formatted text?
Formatted text is text whose appearance has been changed using features such as font, size, style, colour, alignment or spacing.
3. What is Mail Merge?
Mail Merge is a feature used to create many personalised documents, such as letters or labels, by combining a main document with a data source.
4. What is Data Source?
A data source is a file or table containing the records and fields used by Mail Merge, such as names and addresses.
5. What are Table Styles?
Table Styles are predefined formatting styles that can be applied to a table to change its appearance quickly.
6. Write the name of alignments, which are available in MS-Word 2007.
Left, Centre, Right and Justify.
7. What is the difference between the Save and Save As option?
Save saves changes to the current file. Save As creates a new copy with a different name, location or file format.
8. Write the steps to insert WordArt text in a document.
Go to the Insert tab → click WordArt → choose a style → type the required text → format it as needed.
9. What is the need to modify the spacing of the lines or paragraph of your text?
Line and paragraph spacing improves readability, gives the document a neat appearance and helps organise information clearly.
10. How do you insert a table in your document?
Go to the Insert tab → click Table → select the required rows and columns, or choose Insert Table and enter the required numbers.

3. Answer the Following

1. Define the term workbook.
A workbook is an Excel file that contains one or more worksheets.
2. Rohan is new to Excel. His instructor has asked him to open Excel on her PC and questioned about active cell. Help Rohan identify the active cell on his screen.
The active cell is the currently selected cell, shown with a bold or highlighted border. It is the cell where data or a formula will be entered.
3. What is the default alignment of number, text and formula in a spreadsheet?
Numbers are aligned to the right, while text is aligned to the left. Formula results generally follow the alignment of the result type.
4. Sahil has clicked on the cell residing at the intersection of first row and ninth column. What will be the address of the selected cell?
I1.
5. How many cells would be there in the cell range [A1 : B2]?
4 cells — A1, A2, B1 and B2.
6. If = 6 * 5 * 2 is entered in a cell, then what will be the cell content?
60.
7. In a spreadsheet software, the formula =A1+$A$2 was entered in cell A3 and then copied into cell B3. What is the formula copied into B3?
=B1+$A$2.
8. Write down the formula for adding values of cells A1 to A5.
=SUM(A1:A5).
9. State difference between COUNT() and COUNTA() function.
COUNT() counts cells containing numbers. COUNTA() counts non-empty cells, including text and numbers.
10. Write down the importance of legend in charts.
A legend identifies the data series shown in a chart, helping the reader understand what each colour, pattern or marker represents.
11. What is the difference between a workbook and a worksheet?
A workbook is the complete Excel file. A worksheet is an individual spreadsheet page inside a workbook.
12. Define the meaning of formula.
A formula is an expression used to calculate a result in a spreadsheet. It normally begins with an equal sign (=).
13. Suggest the appropriate function for the following situations.
Use the function according to the required calculation: SUM() for adding values, AVERAGE() for average, MAX() for the largest value, and MIN() for the smallest value.
14. Selecting the maximum value out of a range A1 to B20.
=MAX(A1:B20)
15. Calculating average of marks entered in cells E5, F5, G5, H5 and I5.
=AVERAGE(E5:I5)
16. Akriti has entered 49+30 in a cell. The worksheet is not displaying 79 in the cell. Instead, 49+30 is getting displayed. Help Akriti in rectifying the problem.
Enter the expression as a formula by typing =49+30. If it still displays the expression, change the cell format from Text to General and re-enter the formula.
17. For what purpose pie charts are useful?
Pie charts are useful for showing how different parts contribute to a whole, usually as percentages or proportions.
18. Explain the concept of cell referencing along with its various types.
Cell referencing means using a cell address in a formula. Relative reference changes when the formula is copied, e.g. A1. Absolute reference remains fixed, e.g. $A$1. Mixed reference fixes either the row or the column, e.g. $A1 or A$1.

3. Answer the Following

1. Write down the name of default view in a PowerPoint presentation.
Normal view.
2. Differentiate between a presentation and a slide.
A presentation is the complete PowerPoint file containing one or more slides. A slide is an individual page or screen within the presentation.
3. Write use of layouts in PowerPoint.
Layouts provide predefined arrangements of placeholders for titles, text, pictures, charts and other objects on a slide.
4. In PowerPoint 2007 under the Insert tab, there is a button named Text Box. What is the utility of this button?
The Text Box button is used to insert a box in which text can be typed at a desired position on a slide.
5. Animation is a feature, which you can use in your presentation. What is the purpose of this feature?
Animation adds movement or visual effects to text and objects, making a presentation more engaging and helping information appear in a controlled sequence.
6. Write three functions that can be performed in Slide Sorter view of a presentation.
You can rearrange slides, delete slides, and apply or manage slide transitions/timing from Slide Sorter view.
7. How are Header and Footer useful?
Headers and footers can display information such as the date, slide number, presentation title or other repeated information on slides or printed material.
8. Differentiate between Slide Transition and Custom Animation.
Slide Transition is an effect used when moving from one slide to another. Custom Animation controls how individual objects such as text or pictures enter, move or leave a slide.
9. Explain the various views of a slide available in PowerPoint 2007.
Normal view is used to create and edit slides. Slide Sorter view displays slide thumbnails together for arranging them. Slide Show view displays the presentation full-screen. Notes Page view allows speaker notes to be viewed and edited. Slide Master view is used to control common formatting and layout across slides.
