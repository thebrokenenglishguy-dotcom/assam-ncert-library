1. Fill in the Blanks

  1. Identifiers in C programming language start with a letter or underscore (_).
  2. break is a keyword in C — True.
  3. A variable in C can store more than one value at a time — False.
  4. An integer variable typically reserves 4 bytes in memory.
  5. Built-in function used to accept user input from the keyboard is scanf().
  6. Format specifier for accepting an integer value from keyboard is %d.
  7. Every operator in C requires exactly two operands — False.
  8. % sign is used to indicate remainder operation in C.
  9. To compare two float variables in C, we can use relational operators.
  10. When we need to select a set of statements for execution in a C program based on some integral value, a good choice can be to use switch-case construct.
The usual size of int is 4 bytes on modern systems, although the exact size is implementation-dependent.

2. Short Answer Questions

a. If we need to execute many statements when an if condition in C returns true, how can we write them? Write a code segment.
Use braces { } to make a block of statements.
if (condition) { statement1; statement2; statement3; }
b. List five commonly used operators of C programming language with their meaning.
+ addition, - subtraction, * multiplication, / division, % remainder (modulus). Other important operators include relational, logical and assignment operators.
c. The scanf statement should always be preceded by a printf statement in C. Is it true? Explain briefly.
False. A printf() statement is not required before scanf(). It is normally used to give the user a prompt, but scanf() can read input without a preceding printf().

3. Programming Assignments

a. Write a C program and try to declare variables of type int with the following variable names separately: first_variable, secondVariable, ThirdVariable, char, number, *, -, x, 9months, blp24, 8724, dimatala, gomakukh??, I want to be a doctor. Report if any variable declarations are not permitted by the compiler. Analyze the reasons.
Valid identifiers include first_variable, secondVariable, ThirdVariable, number, x, blp24 and dimatala. Invalid identifiers include char (keyword), * and - (operators/symbols), 9months and 8724 (start with a digit), and gomakukh?? and I want to be a doctor. (contain invalid characters/spaces). C identifiers may use letters, digits and underscores, but cannot start with a digit or be a keyword.
int first_variable; int secondVariable; int ThirdVariable; int number; int x; int blp24; int dimatala;
b. Write the following code segment inside the main() function of a C program and run it. Analyse the output.
int var = 7; printf("The value of var is %d.", var); printf("The address of var in memory is %p", &var);
The first line prints 7. The second line prints the memory address of var. The address is different from one execution or computer to another. The %p format specifier is used for a pointer address.
c. Write the following code segment inside the main() function of a C program and run it. Analyse the output.
int p = 9; printf("Size of the variable p is %ld \n", sizeof(p)); printf("Size of an integer is %ld \n", sizeof(int)); printf("Storage for the type of the variable p is %ld \n", sizeof(typeof(p)));
The first two expressions normally produce the same size because p is an int. In standard C, typeof(p) is not part of the standard language; some compilers provide it as an extension. In standard C, use sizeof(p) or sizeof(int) instead. The exact size of int is implementation-dependent.
d. Write a C program to do the following: declare p = 9, q = 7, result = 0; display the result of p+q, p-q, p/q, p*q, p%q, p&&q; then perform ++result, result++, result--; and display result at each step.
#include <stdio.h> int main(void) { int p = 9, q = 7, result = 0; printf("p + q = %d\n", p + q); printf("p - q = %d\n", p - q); printf("p / q = %d\n", p / q); printf("p * q = %d\n", p * q); printf("p %% q = %d\n", p % q); printf("p && q = %d\n", p && q); ++result; printf("After ++result: %d\n", result); result++; printf("After result++: %d\n", result); result--; printf("After result--: %d\n", result); return 0; }
For integer variables, the arithmetic results are 16, 2, 1, 63, 2; p && q is 1 because both values are non-zero. The result values after the three increment/decrement operations are 1, 2, 1.
e. Write a C program to find the area of a rectangle. The length and width of the rectangle are inputs.
#include <stdio.h> int main(void) { float length, width, area; printf("Enter length and width: "); scanf("%f %f", &length, &width); area = length * width; printf("Area = %.2f\n", area); return 0; }
f. Change the programming example B.1 to accept the integers from the keyboard using scanf() function.
The input values can be accepted using scanf() with the %d format specifier.
int a, b; printf("Enter two integers: "); scanf("%d %d", &a, &b);
g. Improve the programming example B.5 to check whether the student scores PASS or FAIL in individual subjects. [Hint: use if clause]
Check each subject mark separately against the pass mark used in Example B.5. The following structure can be adapted to the book's pass-mark value.
if (subject1 >= PASS_MARK) printf("Subject 1: PASS\n"); else printf("Subject 1: FAIL\n"); if (subject2 >= PASS_MARK) printf("Subject 2: PASS\n"); else printf("Subject 2: FAIL\n");
h. Improve the programming example B.5 to check whether every mark entered from the keyboard is positive or not. If any mark is entered as negative, prompt the user to re-enter. [Hint: use if clause and then put scanf()].
do { printf("Enter mark: "); scanf("%d", &mark); if (mark < 0) printf("Invalid mark. Please re-enter.\n"); } while (mark < 0);
i. Write a program in C for awarding student grade (as Example B.5) using switch-case construct.
First convert the student's mark/percentage into a grade code, then use switch to display the corresponding grade. The grade ranges should be kept the same as those specified in Example B.5.
switch (gradeCode) { case 1: printf("FIRST DIVISION"); break; case 2: printf("SECOND DIVISION"); break; case 3: printf("THIRD DIVISION"); break; default: printf("FAIL"); }
