3. Answer the Following Questions

1. What is Database? Give examples.
A database is an organised collection of related data that can be stored, managed and retrieved easily. Examples include a student database, employee database and library database.
2. What is the need for database?
A database helps to store, organise, retrieve, update and manage large amounts of data efficiently. It also reduces duplication and makes information easier to access.
3. Define: Primary key, Foreign key, Candidate key, Super key.
Primary key: A field or set of fields that uniquely identifies each record in a table.
Foreign key: A field that refers to the primary key of another table and helps establish a relationship between tables.
Candidate key: A field or combination of fields that can uniquely identify records and can be selected as the primary key.
Super key: A set of one or more fields that uniquely identifies a record; it may contain additional fields.
4. Differentiate between Flat file database and Relational database.
Flat file database: Data is generally stored in a single table or file, which can cause repetition and redundancy. Relational database: Data is stored in multiple related tables, reducing redundancy and allowing relationships between tables.
5. What are data types? List the various types of data types used in Access 2007 and explain any four of them.
Data types specify what kind of data a field can store. Common Access 2007 data types include Short Text, Memo, Number, Date/Time, Currency, AutoNumber, Yes/No, OLE Object, Hyperlink and Attachment.
Short Text: Stores text and numbers that are not used for calculations.
Number: Stores numerical values used in calculations.
Date/Time: Stores dates and times.
Currency: Stores monetary values.
6. What is a query? Explain the parts of a query window.
A query is a request used to retrieve, filter or manipulate specific data from a database. In Access, the query design window contains a table/field area showing selected tables and their fields, and a design grid where fields, tables, sort order, criteria and other query options are specified.
7. What do you understand by criteria?
Criteria are conditions specified in a query to select only the records that meet a particular requirement. For example, the criterion >=50 can select marks that are 50 or more.
