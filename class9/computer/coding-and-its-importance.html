2. Short Answer Questions

a. How do we write programs in assembly level language?
Programs in assembly language are written using mnemonics or symbolic instructions such as ADD, SUB and MOV. An assembler translates these instructions into machine language.
b. The expression a = b + c can be a statement of which type of programming languages?
It can be a statement in a high-level programming language, such as C.
c. Name the two basic ingredients if we want to write a computer program for solving a problem.
The two basic ingredients are an algorithm for solving the problem and a programming language for expressing the solution.
d. Why is it easier for a human being to write programs in high level language than in machine level language?
High-level languages use words, symbols and statements that are easier for humans to understand. Machine language uses only binary numbers, making programs difficult to write, read and debug.

3. Long Answer Questions

a. Define the term programming. Write the importance of computer programming.
Programming is the process of writing instructions in a programming language to make a computer perform a particular task. It is important because it helps us solve problems, automate tasks, process data, create software and develop websites, applications and other digital systems.
b. Explain the importance of compiler in program execution.
A compiler translates a program written in a high-level language into machine-readable code. It checks the program for errors and reports them to the programmer. After successful compilation, the translated program can be executed by the computer. Thus, a compiler acts as a bridge between high-level programming languages and machine language.
c. Differentiate between algorithm, flowchart and pseudocode.
Algorithm: A step-by-step written procedure for solving a problem.
Flowchart: A graphical representation of an algorithm using standard symbols and arrows.
Pseudocode: A simple, structured description of an algorithm written in language-like statements without following the exact syntax of a programming language.

4. Problem Solving and Algorithm Design Questions

a. Draw a flowchart to find the larger number from two given numbers.
Solution strategy: Start → Input A, B → Check A > B? → If Yes, display A as larger → If No, display B as larger → Stop.
b. Write a solution strategy for finding the largest number among three given numbers. Draw a flowchart for the same.
Solution strategy:
  1. Start.
  2. Input A, B and C.
  3. Set MAX = A.
  4. If B > MAX, set MAX = B.
  5. If C > MAX, set MAX = C.
  6. Display MAX.
  7. Stop.
c. Design an algorithm to find the smallest of N given numbers. Write a pseudocode for the same. Draw a flowchart to represent the solution strategy.
Algorithm: Input N and the numbers. Set MIN to the first number. Compare each remaining number with MIN. If a number is smaller, replace MIN. Finally display MIN.
READ N READ first number MIN = first number FOR each remaining number READ X IF X < MIN THEN MIN = X END IF END FOR PRINT MIN
d. Write a solution strategy for finding the greatest common divisor of two numbers. Draw a flowchart for the same.
Use the Euclidean method: input A and B; while B is not zero, calculate R = A MOD B, then set A = B and B = R. When B becomes zero, A is the GCD. Display A.
e. Write pseudocode for finding the summation of N given numbers. Draw a flowchart for the same.
READ N SUM = 0 FOR i = 1 TO N READ X SUM = SUM + X END FOR PRINT SUM
f. Write a solution strategy for arranging three numbers in ascending order of their values. Draw a flowchart for the same.
Input A, B and C. Compare and interchange values so that A contains the smallest value, B the middle value and C the largest value. Then display A, B and C in that order.
g. Write pseudocode to announce all the even numbers from a given set of numbers. Draw a flowchart for the same.
READ N FOR i = 1 TO N READ X IF X MOD 2 = 0 THEN PRINT X END IF END FOR
