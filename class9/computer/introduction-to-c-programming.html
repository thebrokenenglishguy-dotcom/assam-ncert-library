2. Short Answer Questions

a. While writing a computer program, what does a programmer need to assume about the CPU and storage?
The programmer needs to assume that the computer has a CPU capable of executing instructions and memory/storage for holding the program, data and results. The programmer works with a logical model rather than the detailed physical construction of the hardware.
b. Do we always need Coped to write C programs? Explain.
No. A dedicated IDE is not always necessary to write C programs. A programmer can use a simple text editor to write the source code and then use a C compiler and other tools separately to compile and run it.
c. Why do we need header files? Name a few standard header files in C.
Header files contain declarations and information about functions, macros and other definitions that a C program can use. They help the compiler understand library functions. Examples are stdio.h, stdlib.h, string.h, math.h and ctype.h.

3. Long Answer Questions

a. Explain the process of compilation of a C program. When we save a C program with the name Namaskar.c, what files will be created at each step of compilation?
Compilation changes the C source program into executable machine code through several stages:
  1. Preprocessing: header files and macros are processed; an intermediate preprocessed file such as Namaskar.i is produced.
  2. Compilation: the preprocessed C code is translated into assembly code, such as Namaskar.s.
  3. Assembly: assembly code is converted into an object file, such as Namaskar.o.
  4. Linking: object code and required library code are combined to create the executable program, commonly a.out on Unix-like systems or an .exe executable on Windows.
b. Can we compile an erroneous code in C? If we do not write the function main() in our C program, will it compile successfully?
If a C program contains syntax or compilation errors, the compiler reports errors and cannot produce a valid executable. If main() is missing, the source may be compiled into an object file by some toolchains, but the linking stage normally fails because a C executable requires an entry point such as main(). Therefore, it will not successfully produce a normal executable program.
c. What is a programmer's view of memory? Is it different from actual memory? Explain briefly.
A programmer's view of memory is a logical view in which memory is treated as a collection of addresses and storage locations for variables, instructions and data. It is different from the actual physical memory because the programmer does not normally deal directly with the physical electronic arrangement of memory cells.

4. Programming Assignments

a. Write and execute a C program to print your name.
#include <stdio.h> int main(void) { printf("Your Name"); return 0; }
b. Write and execute a C program to print your name and your mother's name in two different lines but using a single printf.
#include <stdio.h> int main(void) { printf("Your Name\nYour Mother's Name"); return 0; }
c. Write and execute a C program to print the sentence “I am from Assam. I am a responsible citizen of my country.” five times.
#include <stdio.h> int main(void) { printf("I am from Assam. I am a responsible citizen of my country.\n"); printf("I am from Assam. I am a responsible citizen of my country.\n"); printf("I am from Assam. I am a responsible citizen of my country.\n"); printf("I am from Assam. I am a responsible citizen of my country.\n"); printf("I am from Assam. I am a responsible citizen of my country.\n"); return 0; }
d. Remove the semicolons (;) from the C program of the previous question. Compile the program and check the errors. Note the line numbers and then rectify them.
The compiler reports syntax errors at the statements where the semicolons are missing. The exact line numbers depend on how the program is entered. Add ; at the end of each printf() statement and the return 0 statement, then compile again.
e. Write and execute a C program to print your name in the order Last name First name. But you will pass them in First name Last name order inside printf. (Hint: use proper escape sequence).
#include <stdio.h> int main(void) { printf("First Name\b\b\b\b\b\b\bLast Name"); return 0; }
Note: The exact number of backspaces depends on the length of the first name. The \b escape sequence moves the cursor one position backward.
