4. Short Answer Questions

a. Who is known as the “father of the modern computer”?
Charles Babbage is known as the father of the modern computer.
b. What is a computer?
A computer is an electronic device that accepts data, processes it according to instructions, stores it and produces useful information.
c. Name a popular pointing device.
Mouse.
d. Who invented Jacquard’s loom?
Joseph Marie Jacquard.
e. Give the full form of ENIAC and EDVAC.
ENIAC — Electronic Numerical Integrator and Computer. EDVAC — Electronic Discrete Variable Automatic Computer.
f. Give two examples of second-generation computers.
IBM 1401 and IBM 1620.
g. What is AI?
Artificial Intelligence (AI) is the ability of a computer or machine to perform tasks that normally require human intelligence.
h. Give two examples of secondary memories.
Hard disk and pen drive.
i. What does the CPU do?
The CPU processes data, executes instructions and controls the operations of the computer.
j. Why do we use secondary memory?
We use secondary memory to store large amounts of data and programs permanently for future use.
k. Give two examples of pointing devices.
Mouse and joystick.
l. Which input device is used to record sound?
Microphone.
m. What is the use of barcode reader?
A barcode reader reads barcodes and converts the information into a form that a computer can process.
n. What is system software? Give two examples.
System software manages computer hardware and provides a platform for applications. Examples: operating system and utility software.
o. What is the role of CU?
The Control Unit (CU) controls and coordinates all operations of the computer.
p. What is the function of ALU?
The ALU performs arithmetic and logical operations.
q. What do you understand by memory word?
A memory word is a group of bits that a computer can process as one unit.
r. What is the function of compiler?
A compiler translates a high-level language program into machine language and reports errors in the program.
s. What is the main limitation of a computer?
A computer cannot think, judge or make decisions on its own. It works according to the instructions given to it.
t. Mention three main features of a computer.
High speed, high accuracy and large storage capacity.
u. What is a computer program?
A computer program is a set of instructions written to make a computer perform a specific task.
v. What are the fundamental components of a computer system?
The fundamental components are input unit, CPU, memory/storage unit and output unit.
w. What is application software?
Application software is software designed to perform specific tasks for users.
x. Mention various categories of application software.
The main categories are general-purpose application software and special-purpose application software.
y. What do you understand by computer memory?
Computer memory is the storage area used to hold data, instructions and results for processing.
z. What is the binary equivalent of hexadecimal 15?
Hexadecimal 15 is F, and its binary equivalent is 1111₂.

5. Long Answer Questions

a. Mention four features of a computer system.
Four important features are: (1) high speed, (2) high accuracy, (3) large storage capacity, and (4) diligence, meaning it can work repeatedly without getting tired.
b. Mention the characteristic features of third-generation computers.
Third-generation computers used integrated circuits (ICs). They were smaller, faster, more reliable and consumed less power than second-generation computers. They also supported higher-level programming languages and had better storage and operating systems.
c. What do you understand by generation of computers? Mention two disadvantages of first-generation computers.
A generation of computers refers to a stage in computer development based mainly on the technology used. First-generation computers used vacuum tubes. Two disadvantages were very large size and high power consumption. They also produced much heat.
d. Describe the functioning of CPU.
The CPU works mainly through the instruction cycle. The Control Unit fetches instructions from memory and controls their execution. The ALU performs arithmetic and logical operations. Registers temporarily hold data, instructions and intermediate results. The processed result is then stored or sent to the output unit.
e. Draw a block diagram of a computer system.
Basic block diagram: Input Unit → CPU ↔ Memory/Storage → Output Unit. The CPU contains the Control Unit (CU), Arithmetic and Logic Unit (ALU) and registers.
f. What are the categories of printers? Explain.
Printers are mainly of two types: impact printers and non-impact printers. Impact printers print by striking a ribbon against paper, such as dot-matrix printers. Non-impact printers print without striking the paper, such as inkjet and laser printers.
g. What is a bus? Explain three types of buses.
A bus is a set of electrical pathways used to transfer information between computer components. Data bus carries data, address bus carries addresses, and control bus carries control signals.
h. What are functions of primary storage area?
Primary storage holds data and instructions currently being used by the CPU, stores intermediate results and keeps programs available for processing. It provides fast access to the CPU.
i. Explain three types of ROM.
PROM can be programmed once. EPROM can be erased using ultraviolet light and programmed again. EEPROM can be electrically erased and reprogrammed.
j. What is a purpose of a language processor? Explain the three language processors.
A language processor converts a program written in a programming language into machine-understandable form. An assembler converts assembly language to machine language. A compiler translates the whole high-level program into machine code. An interpreter translates and executes a program line by line.
k. Differentiate between data and information.
Data is raw, unprocessed facts and figures. Information is meaningful and useful data obtained after processing. Example: marks entered for students are data; the calculated average or result is information.
l. Write short note on fifth-generation computers.
Fifth-generation computers are based on advanced technologies such as artificial intelligence, parallel processing and natural-language processing. They aim to make computers more intelligent and capable of learning, reasoning and solving complex problems.
m. What are basic differences between the four generations of computers?
First generation used vacuum tubes; second used transistors; third used integrated circuits; and fourth used microprocessors. Each generation generally became smaller, faster, more reliable and more energy-efficient.
n. Write a short note on MARK I.
Harvard Mark I was an early electromechanical automatic calculator developed by Howard Aiken with IBM. It was a large machine used for automatic numerical calculations and was completed in 1944.
o. Explain the two main types of secondary memory.
Secondary memory can be broadly divided into magnetic storage and optical storage. Magnetic storage uses magnetized surfaces, such as hard disks and magnetic tapes. Optical storage uses laser technology, such as CDs and DVDs.
p. Describe various types of magnetic media.
Common magnetic media include hard disks, magnetic tapes and older floppy disks. They store data by changing the magnetic state of small areas on their surfaces.
q. Mention some areas where computers are used widely.
Computers are widely used in education, banking, business, medicine, science and research, communication, transportation, government offices, entertainment and industry.
r. What are the major operations performed by a computer?
The major operations are input, processing, storage and output. A computer accepts data, processes it, stores data/results and produces information.
s. Differentiate between the following pairs.
I. Input unit and Output unit: The input unit enters data and instructions into a computer; the output unit presents processed results to the user.
II. RAM and ROM: RAM is volatile and can be read and written during processing; ROM is non-volatile and mainly stores permanent instructions.
III. Soft copy and Hard copy: A soft copy is an electronic form displayed on a screen; a hard copy is a physical printed form.
IV. Primary memory and Secondary memory: Primary memory is fast and directly accessible by the CPU; secondary memory provides long-term storage and is generally slower.
V. Impact printer and Non-impact printer: Impact printers strike the paper while printing; non-impact printers print without physical striking.
VI. Assembler and Compiler: An assembler translates assembly language into machine language; a compiler translates a high-level language program into machine code.
VII. Hardware and Software: Hardware is the physical part of a computer; software is the set of programs and instructions.
VIII. System software and Application software: System software manages hardware and provides a platform for applications; application software performs specific user tasks.
