2. Short Answer Questions

a. Define a multicore system. Is Intel i7 a multicore system? Explain briefly.
A multicore system has two or more processing cores in a single processor or chip. Intel Core i7 processors are available in multicore versions, so an i7 model with multiple cores is a multicore processor.
b. What is GPU? Why do we need GPU in our computer system?
GPU stands for Graphics Processing Unit. It performs many calculations in parallel and is especially useful for graphics, video, 3D rendering, games and other highly parallel workloads.
c. Define 3D NoC architecture. What technology is typically used for connecting one layer with another in case of 3D NoC architecture?
3D NoC (Network-on-Chip) architecture connects processing cores and other components through a network arranged across multiple chip layers. Vertical connections such as through-silicon vias (TSVs) are typically used to connect one layer with another.
d. What is NLP? Mention one of the critical challenges of NLP.
NLP stands for Natural Language Processing. It enables computers to understand and process human language. A major challenge is understanding the context, ambiguity and different meanings of human language.
e. What is utility computing? Write one of the primary reasons for its popularity in recent times.
Utility computing is a model in which computing resources such as storage and processing are provided as a service and users pay according to their usage. Its popularity is largely due to flexible, on-demand access without having to purchase and maintain all the required infrastructure.
f. What is mobile cloud computing? How does this technology become handy for mobile phones to run several applications?
Mobile cloud computing uses cloud resources to provide storage and processing for mobile devices. A mobile phone can send demanding tasks to cloud servers, reducing the processing and storage burden on the phone and helping it run applications efficiently.
g. Write one of the major challenges of MCC while running critical user applications.
A major challenge of Mobile Cloud Computing (MCC) is network dependence and latency. A weak or unreliable network can delay communication with the cloud and affect critical applications.

3. Long Answer Questions

a. Is multicore system a good choice? Explain its merits, demerits and challenges.
Yes, multicore systems are useful because several cores can execute tasks in parallel. They can improve performance, multitasking and energy efficiency compared with simply increasing clock speed. However, applications must be designed to use multiple cores effectively. Synchronization, communication between cores, heat dissipation and programming parallel tasks are important challenges.
b. What is near memory computation? How is it different from traditional computation? Why are scientists doing research on memory computation?
Near-memory computation places processing close to memory so that data does not have to travel long distances between the processor and memory. Traditional systems usually move data between separate CPU and memory units. Near-memory approaches can reduce data movement, latency and energy consumption. Researchers study them because modern applications process very large amounts of data.
c. What is machine learning? Explain its importance in today's era.
Machine learning is a branch of artificial intelligence in which computers learn patterns from data and use them to make predictions or decisions. It is important in areas such as recommendation systems, speech recognition, image analysis, fraud detection, healthcare and automation.
d. What is an artificial neural network? Differentiate between deep learning and reinforcement learning.
An artificial neural network (ANN) is a computing model inspired by interconnected neurons in the brain. Deep learning uses neural networks with many layers to learn complex patterns from large amounts of data. Reinforcement learning learns through interaction with an environment, using rewards and penalties to improve actions.
e. Write a short note on cloud computing.
Cloud computing provides computing resources such as servers, storage, databases and applications over a network, usually the Internet. Users can access resources when needed without owning all the physical infrastructure. It offers scalability, flexibility and pay-as-you-use services.
f. What do you understand by the term IoT? How can IoT impact human lives in the near future?
IoT, or Internet of Things, is a system in which physical devices with sensors and network connectivity collect and exchange data. IoT can support smart homes, healthcare monitoring, smart agriculture, traffic management, industries and energy management. It can make many services more automated and connected.
g. Explain MEC framework with a diagram. How is it different from MCC?
MEC (Mobile Edge Computing) places computing and storage resources close to mobile users, such as at the network edge. This reduces the distance data must travel and can lower latency. MCC (Mobile Cloud Computing) generally sends demanding tasks to remote cloud infrastructure. MEC therefore brings computation closer to the user, while MCC commonly relies on more distant cloud resources.
MEC framework: Mobile User/Device → Access Network → Edge/MEC Server → Core Network/Cloud. The edge server processes suitable tasks close to the user and can forward other tasks to the central cloud.
