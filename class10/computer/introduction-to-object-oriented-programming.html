I. Short Answer Questions

a. What do you mean by programming paradigm?

A programming paradigm is a method or style of writing and organizing a computer program.

b. Define object.

An object is an entity that contains data and functions together.

Example: A Student object can have name, age and marks.

c. Define class.

A class is a blueprint or template used to create objects.

Example: Student can be a class, and individual students can be its objects.

d. What is encapsulation?

Encapsulation means combining data and the functions that operate on that data into a single unit called a class.

e. What is data hiding?

Data hiding means preventing direct access to the internal data of an object and allowing access only through controlled methods.

f. What is polymorphism?

Polymorphism means one name can have many forms or behaviours.

For example, the same function name may perform different tasks depending on the situation.

g. Name four object-oriented programming languages.

  1. C++
  2. Java
  3. Python
  4. C#

h. Name two procedure-oriented programming languages.

  1. C
  2. FORTRAN

i. Name the first object-oriented language.

Simula is considered the first object-oriented programming language.

j. What is abstraction?

Abstraction means showing only the important information and hiding unnecessary implementation details.

Example: We can use an ATM without knowing how its internal system works.

II. Long Answer Questions

a. Mention four characteristics of procedure-oriented programming.

  1. Procedure-based: The program is divided into functions or procedures.
  2. Top-down approach: The problem is divided into smaller parts step by step.
  3. Data is separate: Data and functions are generally treated separately.
  4. Functions are important: The main focus is on the functions or procedures that perform tasks.

Example: C is a commonly used procedure-oriented programming language.

b. Mention two advantages and two disadvantages of procedure-oriented programming.

Advantages:

  1. Easy to understand: Programs are divided into functions, making them easier to follow.
  2. Easy to implement: Small problems can be solved using simple functions.

Disadvantages:

  1. Less data security: Data can often be accessed by different functions.
  2. Difficult to manage large programs: Large programs can become complicated because data and functions are separate.

c. Explain four features of OOP.

1. Encapsulation

It combines data and functions into one unit called a class.

2. Abstraction

It shows only the important information and hides unnecessary details.

3. Inheritance

It allows a new class to use the properties and functions of an existing class.

4. Polymorphism

It allows the same name or interface to have different behaviours.

d. List four advantages of OOP.

  1. Code reusability: Existing code can be reused using inheritance.
  2. Data security: Data can be protected using data hiding.
  3. Easy maintenance: Large programs can be divided into classes and objects.
  4. Flexibility: Polymorphism allows the same interface to perform different tasks.
