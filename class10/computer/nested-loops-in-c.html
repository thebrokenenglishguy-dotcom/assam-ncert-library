         *
       * * *
     * * * * *
   * * * * * * *
     * * * * *
       * * *
         *
#include <stdio.h>

int main()
{
    int i, j;

    /* Upper half */
    for(i = 1; i <= 4; i++)
    {
        for(j = 1; j <= 4 - i; j++)
        {
            printf("  ");
        }

        for(j = 1; j <= 2 * i - 1; j++)
        {
            printf("* ");
        }

        printf("\n");
    }

    /* Lower half */
    for(i = 3; i >= 1; i--)
    {
        for(j = 1; j <= 4 - i; j++)
        {
            printf("  ");
        }

        for(j = 1; j <= 2 * i - 1; j++)
        {
            printf("* ");
        }

        printf("\n");
    }

    return 0;
}

2. Modify Question 1 to accept the number of lines as input.

The main change is that instead of fixing the number of rows, we take the number of rows from the user.

Example for pattern (a):

Enter number of lines: 4

1 2 3
1 2 3
1 2 3
1 2 3
#include <stdio.h>

int main()
{
    int i, j, n;

    printf("Enter number of lines: ");
    scanf("%d", &n);

    for(i = 1; i <= n; i++)
    {
        for(j = 1; j <= 3; j++)
        {
            printf("%d ", j);
        }

        printf("\n");
    }

    return 0;
}

Important: Previously i <= 5; now i <= n, where n is entered by the user.

To make a pattern dynamic, we take the number of lines from the user.

#include <stdio.h>

int main()
{

4. What is a nested loop? Why do we use nested loops?

Nested loop

  • A nested loop is a loop placed inside another loop.
  • The inner loop runs for every iteration of the outer loop.
for(i = 1; i <= 3; i++)
{
    for(j = 1; j <= 3; j++)
    {
        printf("* ");
    }

    printf("\n");
}
  • Outer for loop → controls the rows.
  • Inner for loop → controls the columns.

Why do we use nested loops?

  • To create patterns.
  • To work with rows and columns.
  • To process tables and matrices.
  • To repeat one operation inside another repeated operation.

5. Do outer and inner loops need to be the same type?

No. The outer and inner loops do not have to be the same type.

We can use different types of loops.

#include <stdio.h>

int main()
{
    int i, j;

    for(i = 1; i <= 3; i++)
    {
        j = 1;

        while(j <= 3)
        {
            printf("* ");
            j++;
        }

        printf("\n");
    }

    return 0;
}

We can also use:

  • while inside for
  • for inside while
  • do-while inside for
  • for inside do-while

So, the type of inner loop can be different from the outer loop.

6. Can we put a third loop inside the inner loop?

Yes. We can put another loop inside the inner loop. This is called a three-level nested loop.

#include <stdio.h>

int main()
{
    int i, j, k;

    for(i = 1; i <= 2; i++)
    {
        for(j = 1; j <= 2; j++)
        {
            for(k = 1; k <= 2; k++)
            {
                printf("%d %d %d\n", i, j, k);
            }
        }
    }

    return 0;
}

Output:

1 1 1
1 1 2
1 2 1
1 2 2
2 1 1
2 1 2
2 2 1
2 2 2

Therefore, a loop can contain another loop, and that loop can contain a third loop.
