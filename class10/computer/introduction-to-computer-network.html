2. Why hostname should not be used to identify a computer in a computer network?

  • A hostname is simply a name given to a computer.
  • It may be changed.
  • The same hostname can sometimes be used on different networks.
  • Therefore, a hostname is not a reliable unique identification of a computer.
  • An IP address or MAC address is more suitable for identifying a device on a network.

3. Give five examples of valid and five examples of invalid IPv4 addresses.

An IPv4 address has four parts, separated by dots. Each part must be between 0 and 255.

Five valid IPv4 addresses:

  1. 192.168.1.1 ✅
  2. 10.0.0.1 ✅
  3. 172.16.5.20 ✅
  4. 8.8.8.8 ✅
  5. 127.0.0.1 ✅

Five invalid IPv4 addresses:

  1. 256.1.1.1 ❌ → 256 is greater than 255.
  2. 192.168.1 ❌ → only 3 parts.
  3. 192.168.1.1.5 ❌ → 5 parts.
  4. 192.168.-1.1 ❌ → negative number.
  5. 192.168.1.abc ❌ → contains letters.
Easy rule: IPv4 = 4 parts + each part 0–255.

4. Can we compare HTTP and FTP protocols? Mention their functionality.

Yes, HTTP and FTP can be compared because both are network protocols, but they have different purposes.

HTTPFTP
HTTP means HyperText Transfer Protocol.FTP means File Transfer Protocol.
It is mainly used for accessing web pages and web resources.It is mainly used for transferring files.
It is commonly used between a web browser and web server.It is commonly used between an FTP client and FTP server.

In short:

  • HTTP → Web pages
  • FTP → Files

5. How many 16-port switches are required to connect 31 computers in a network?

We need 3 switches.

Why?

  • Each switch has 16 ports.
  • To connect 31 computers, 2 switches are not enough because they provide only 32 ports, but some ports must be used to connect the switches together.
  • With 3 switches, there are 48 ports.
  • The switches need ports to connect with each other.
  • The remaining ports are enough for all 31 computers.

Answer = 3 × 16-port switches ✅
