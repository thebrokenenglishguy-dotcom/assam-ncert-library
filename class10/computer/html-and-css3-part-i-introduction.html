III. Application Based Questions

1. Yashvi was styling an HTML document using CSS. She wants to add styles directly to an HTML tag using the style attribute with the tag. How can she do this?

She can use Inline CSS.

The CSS is written directly inside the style attribute of the HTML tag.

<p style="color: blue; font-size: 20px;">
    Hello World
</p>

Here, style is the attribute.

2. Rohan wants to divide his web page into different sections so that the content is easily readable. Which tag can he use for this? Which attributes can he use to define some extra properties of this tag?

  • He can use the <div> tag.
  • The <div> tag is used to divide a web page into different sections.
  • He can use attributes such as id, class, and style.
<div id="header" style="background-color: yellow;">
    Welcome to my website
</div>

3. Kirti wants to set the image of a park as the background of her web page but she is unable to do it. Which tag should she use to do so? Give the syntax.

  • She can use the <body> tag.
  • The background attribute can be used to set a background image.
<body background="park.jpg">

Here, park.jpg is the image used as the background.

IV. Answer the Following

1. What is a markup language?

  • A markup language is a language used to add special codes or tags to text.
  • These tags tell the computer how the content should be displayed.
  • HTML is an example of a markup language.

2. Write some features of HTML.

  1. HTML is a markup language.
  2. It is used to create web pages.
  3. It uses tags to define webpage content.
  4. HTML is easy to learn and use.
  5. It can be used with CSS and JavaScript.
  6. HTML files can be viewed using a web browser.

3. Explain the terms tags and attributes with the help of an example.

Tags: Tags are special codes used in HTML. They tell the browser how to display the content.

Attributes: Attributes provide additional information or properties about an HTML tag. They are written inside the opening tag.

<p style="color: blue;">Hello</p>
  • <p> and </p> are tags.
  • style is an attribute.
  • color: blue is the value given to the attribute.

4. How are comments useful?

  1. They help us write notes in the HTML code.
  2. They explain what a particular part of the code does.
  3. They make the code easier to understand.
  4. Comments are not displayed on the web page.
  5. They help programmers remember important information.
<!-- This is the heading of the page -->
<h1>My Website</h1>

5. What are Cascading Style Sheets? Name the different methods available for applying Style rules in an HTML document.

CSS (Cascading Style Sheets) is used to style and design HTML web pages.

It can change things such as:

  • Text colour
  • Font size
  • Background colour
  • Spacing
  • Page layout

Three methods of applying CSS:

  1. Inline CSS — CSS is written inside the style attribute.
  2. Internal CSS — CSS is written inside the <style> tag in the HTML document.
  3. External CSS — CSS is written in a separate .css file and linked to the HTML document.
Easy way to remember: Inline → Inside the tag | Internal → Inside the HTML file | External → Separate CSS file

6. Differentiate between Internal CSS and External CSS.

Internal CSSExternal CSS

It uses the <style> tag.It uses a separate CSS file.

Example of Internal CSS:

<style>
p {
    color: blue;
}
</style>

Example of External CSS:

<link rel="stylesheet" href="style.css">

    color: blue;
}

Lab Activity

1. Create a web page that serves as an invitation card to your birthday party.

A simple example:

<!DOCTYPE html>
<html>
<head>
    <title>Birthday Invitation</title>

    <style>
        body {
            text-align: center;
            background-color: lightyellow;
        }

        h1 {
            color: purple;
        }

        p {
            font-size: 20px;
        }
    </style>
</head>

<body>

    <h1>🎉 Birthday Party 🎉</h1>

    <h2>You are invited!</h2>

    <p>Come and celebrate my birthday with me.</p>

    <p><b>Date:</b> 15 October</p>
    <p><b>Time:</b> 6:00 PM</p>
    <p><b>Place:</b> My Home</p>

    <h2>See you there! 😊</h2>

</body>
</html>

2. Create a web page that serves as a guide for mathematical formulas using HTML tags along with CSS properties.

Example:

<!DOCTYPE html>
<html>
<head>
    <title>Mathematical Formulas</title>

    <style>
        body {
            background-color: lightblue;
        }

        h1 {
            color: darkblue;
        }

        p {
            font-size: 20px;
        }
    </style>
</head>

<body>

    <h1>Mathematical Formulas</h1>

    <p><b>Area of Circle:</b> πr²</p>

    <p><b>Area of Rectangle:</b> Length × Breadth</p>

    <p><b>Simple Interest:</b> (P × R × T) / 100</p>

    <p><b>Speed:</b> Distance / Time</p>

</body>
</html>

⭐ Important Things to Remember

  • HTML → Creates the structure of a webpage
  • CSS → Designs/styles the webpage
  • Tag → Defines an HTML element
  • Attribute → Gives extra information to a tag
  • Inline CSS → Inside the HTML tag
  • Internal CSS → Inside <style>
  • External CSS → Separate .css file
  • <br> → New line
  • <hr> → Horizontal line
  • <div> → Divides content into sections
  • <!-- --> → HTML comment
