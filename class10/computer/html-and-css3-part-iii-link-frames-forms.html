I. Fill in the Blanks

1. The web pages of a website are linked to each other using __________.

Answer: Hyperlinks

2. The attribute __________ is used to create a hyperlink between two or more HTML codes.

Answer: href

3. When you move the mouse pointer over a link, the mouse pointer changes its shape from an arrow to a __________.

Answer: hand

4. The __________ attribute of the <audio> tag indicates that you can replay the audio file once it is finished.

Answer: loop

5. The small rectangular areas created in the main browser window are known as __________.

Answer: frames

6. The __________ attribute of the frame tag tells the browser which HTML page to load into the frame.

Answer: src

7. __________ attribute of the frame tag attaches the default URL.

Answer: base

8. __________ allow multiple HTML documents to be presented as independent windows within one browser window.

Answer: Frames

9. The __________ tag collects the information from the user.

Answer: <form>

III. Application Based Questions

1. Rohan wants to divide a web page into four sections. Which tag should he use to accomplish this?

  • He can use the <frameset> tag to divide the browser window into different sections.
  • A frameset can contain multiple frames.
<frameset rows="25%,25%,25%,25%">
    <frame src="page1.html">
    <frame src="page2.html">
    <frame src="page3.html">
    <frame src="page4.html">
</frameset>

2. Rahim is creating a website in which he wants to use different images as links to the web pages. He is also interested in adding some video clips in his website. Can you suggest him the required tags to include the said elements?

He can use:

  • <a> tag → to create links.
  • <img> tag → to add images.
  • <video> tag → to add video clips.
<a href="page.html">
    <img src="photo.jpg" alt="Click here">
</a>

<video controls>
    <source src="video.mp4">
</video>

3. Ritika was writing an article using HTML. The article contains some external links to other websites. How can she link these together so that the user can visit the destination of the external links by clicking on them?

  • She should use the <a> (anchor) tag.
  • The href attribute is used to specify the URL of the external website.
<a href="https://www.example.com">
    Visit Website
</a>

When the user clicks Visit Website, the external website opens.

4. Priyanka wants to create a form but she has forgotten the tag used to create the form. Can you help her with the solution?

  • She should use the <form> tag.
  • It is used to create an HTML form for collecting information from users.
<form>
    Name: <input type="text">
    <input type="submit">
</form>

IV. Answer the Following

1. Why do you include hyperlinks in your web page? Give any two reasons.

Hyperlinks are used:

  1. To connect one web page to another.
  2. To allow users to visit another website or resource easily.

They make navigation between web pages easy.

3. What are frames? How are they useful?

  • Frames divide a browser window into several smaller sections.
  • Each section can display a different HTML document.
  • They allow multiple web pages to be displayed in one browser window.

Uses of frames:

  1. They can divide a webpage into different sections.
  2. Different HTML pages can be displayed at the same time.
  3. They can make navigation easier.

4. What are two types of text input in HTML web forms?

The two types are:

  1. Single-line text input – used for short information such as name or city.
  2. Multi-line text input – used for longer information such as comments or messages.
<input type="text">

For multi-line input:

<textarea></textarea>

5. Which input control is most useful for questions requiring a simple yes or no answer?

The Radio Button is useful for questions requiring a Yes or No answer.

<input type="radio" name="answer"> Yes
<input type="radio" name="answer"> No

6. What is the use of password control in HTML forms?

  • Password control is used to enter passwords securely.
  • The characters typed by the user are hidden or displayed as dots/asterisks.
<input type="password">

7. What is the use of <INPUT> tag?

The <input> tag is used to create different types of input controls in a form, such as:

  • Text box
  • Password box
  • Radio button
  • Checkbox
  • Submit button
  • Reset button
<input type="text">

8. What are the uses of Submit and Reset buttons?

Submit button

  • It is used to send the information entered in a form.
<input type="submit">

Reset button

  • It is used to clear the entered information and return the form to its initial state.
<input type="reset">

V. Lab Activity

1. Create a web page where a person has to choose a day of the month from a drop-down list. The page should also allow the person to enter two lines on what the person plans to do on.

Example:

<!DOCTYPE html>
<html>
<head>
    <title>My Plans</title>
</head>

<body>

    <h1>Choose a Day</h1>

    <form>

        <label>Select a day:</label>

        <select>
            <option>1</option>
            <option>2</option>
            <option>3</option>
            <option>4</option>
            <option>5</option>
            <option>6</option>
            <option>7</option>
            <option>8</option>
            <option>9</option>
            <option>10</option>
        </select>

        <br><br>

        <label>My Plan:</label><br>

        <textarea rows="2" cols="30">
        </textarea>

        <br><br>

        <input type="submit">

    </form>

</body>
</html>

Important tags used:

  • <select> → creates a drop-down list
  • <option> → creates options in the list
  • <textarea> → allows multiple lines of text
  • <form> → creates the form
  • <input type="submit"> → submits the form
