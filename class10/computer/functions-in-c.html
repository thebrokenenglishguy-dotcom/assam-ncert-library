Exercise

1. What is a global variable in C? Why do we need such a variable?

A global variable is a variable declared outside all functions.

Why do we need it?

  • It can be accessed by different functions in the program.
  • It remains available throughout the execution of the program.
  • It is useful when the same data needs to be shared by several functions.
int x = 10;   // Global variable

int main()
{
    printf("%d", x);
    return 0;
}

2. Write the syntax of a function declaration. The function is calculateAge().

return_type function_name(parameters);

For calculateAge():

int calculateAge(int currentYear, int birthYear);
  • int → return type
  • calculateAge → function name
  • currentYear and birthYear → parameters

3. Write the function definition of calculateAge().

int calculateAge(int currentYear, int birthYear)
{
    int age;

    age = currentYear - birthYear;

    return age;
}

Example: Current year = 2026, Birth year = 2006 → Age = 20.

4. What are different types of functions in C? Differentiate among them.

1. Library Functions

  • Already provided by C libraries.
  • We can directly use them by including the required header file.

Examples:

printf()
scanf()
sqrt()
strlen()

2. User-defined Functions

  • Created by the programmer according to the requirement.
int square(int n)
{
    return n * n;
}

Difference:

  • Library function → already available in C libraries.
  • User-defined function → created by the programmer.

5. Differentiate between caller and callee functions. Identify them in a C program.

Caller function: A function that calls another function.

Callee function: A function that is called by another function.

#include <stdio.h>

void message()
{
    printf("Hello");
}

int main()
{
    message();

    return 0;
}

main() → Caller
message() → Callee

6. When do we call a function user-defined? Is printf() a user-defined function?

A function is called user-defined when it is created and defined by the programmer.

int square(int n)
{
    return n * n;
}

printf() is not a user-defined function.

  • printf() is a library function.
  • It is provided by the C standard library.
  • It is declared in the stdio.h header file.

7. Can we have two functions with the same name but different numbers of parameters in a single C program?

No. C does not support function overloading.

This is not allowed in C:

int add(int a, int b)
{
    return a + b;
}

int add(int a, int b, int c)
{
    return a + b + c;
}

Both functions have the name add(), so this causes an error.

C → No function overloading
C++ → Supports function overloading

8. What are different components of a function? Show with a complete C program.

The main components are:

  1. Function declaration/prototype
  2. Function call
  3. Function definition
  4. Parameters
  5. Return value
#include <stdio.h>

/* Function declaration */
int add(int a, int b);

int main()
{
    int result;

    /* Function call */
    result = add(10, 20);

    printf("Sum = %d", result);

    return 0;
}

/* Function definition */
int add(int a, int b)
{
    return a + b;
}
  • int add(int a, int b); → Function declaration
  • add(10, 20); → Function call
  • int add(int a, int b) → Function definition
  • a and b → Parameters
  • return a + b; → Return value

9. Define recursive function. Can we use a recursive function to solve all kinds of problems?

A recursive function is a function that calls itself.

int count(int n)
{
    if(n == 0)
        return 0;

    return count(n - 1);
}

Can recursion solve all problems? No.

  • Some problems are suitable for recursion.
  • Some problems are better solved using loops.
  • Recursion can use more memory because each function call is stored in the call stack.

10. Consider the code and list the important error.

int fun(int x)
{
    if(x %2 == 0)
        return 1;
    else
        return 0;
}

int main()
{
    int number;

    printf("\n Enter the number: ");
    scanf("%d", &number);

    int x = fun();

    return 0;
}

The function is declared as int fun(int x), so it requires one argument. But it is called as fun(), with no argument.

Correct statement:

int x = fun(number);

The source notes that the important problem intended by the exercise is the missing argument.

13. Write a C program with a function search() that searches an element in an array and returns its index.

#include <stdio.h>

int search(int a[], int size, int key)
{
    int i;

    for(i = 0; i < size; i++)
    {
        if(a[i] == key)
            return i;
    }

    return -1;
}

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int key, index;

    printf("Enter element to search: ");
    scanf("%d", &key);

    index = search(a, 5, key);

    if(index != -1)
        printf("Element found at index %d", index);
    else
        printf("Element not found");

    return 0;
}

If the element is not found, return -1; is used.

14. Write a C program with a recursive function to find the sum of first N natural numbers.

#include <stdio.h>

int sum(int n)
{
    if(n == 0)
        return 0;

    return n + sum(n - 1);
}

int main()
{
    int n, result;

    printf("Enter N: ");
    scanf("%d", &n);

    result = sum(n);

    printf("Sum = %d", result);

    return 0;
}

Example: If N = 5:

5 + 4 + 3 + 2 + 1 = 15

How recursion works:

sum(5)
= 5 + sum(4)
= 5 + 4 + sum(3)
= 5 + 4 + 3 + sum(2)
= 5 + 4 + 3 + 2 + sum(1)
= 15

15. Write a C program with a function add() that accepts three array indices and returns the sum of the elements stored at those indices.

Given array:

Index:    0  1  2  3  4  5
Element:  7  8  8  0  0  9

add(0, 2, 5) returns 7 + 8 + 9 = 24.

#include <stdio.h>

int add(int a[], int i, int j, int k)
{
    return a[i] + a[j] + a[k];
}

int main()
{
    int a[6] = {7, 8, 8, 0, 0, 9};
    int result;

    result = add(a, 0, 2, 5);

    printf("Sum = %d", result);

    return 0;
}
Output: Sum = 24
