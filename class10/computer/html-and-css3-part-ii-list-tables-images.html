III. Application Based Questions

a. Ruchika was making an ordered list and she noticed that the items of the list by default started with numbers. She wants to use Roman numerals for numbering. How can she do this?

She can use the type attribute with the <ol> tag.

<ol type="I">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Here, type="I" displays the list as:

I. HTML
II. CSS
III. JavaScript

b. Rohan has created a table and he wants that the table border should be collapsed into a single border. Which property should he use?

  • He should use the border-collapse property.
  • Its value should be collapse.
table {
    border-collapse: collapse;
}

c. Ashmita has added few images on her web page but she wants to keep some provisions for the visually impaired people or users using text-based browsers so that they get the description for the images. Which attribute should she use?

  • She should use the alt attribute.
  • It provides alternative text describing the image.
<img src="park.jpg" alt="A beautiful park">

IV. Answer the Following

a. Differentiate between the <OL> and <UL> tag.

<OL><UL>
<OL> means Ordered List.<UL> means Unordered List.
Items are shown in a particular order.Items do not have a numbered order.
Items are normally marked with numbers.Items are normally marked with bullets.
Example: 1, 2, 3Example: •, •, •
<ol>
    <li>Apple</li>
    <li>Mango</li>
</ol>
<ul>
    <li>Apple</li>
    <li>Mango</li>
</ul>

b. Write the syntax for using list-style-type property.

selector {
    list-style-type: value;
}

Example:

ul {
    list-style-type: square;
}

c. Define Padding property.

  • Padding is the space between the content of an element and its border.
  • It creates space inside the border.
p {
    padding: 10px;
}

d. What is description list? Define the different tags used to create a description.

A description list is a list used to show terms and their descriptions.

It uses three main tags:

  1. <dl> – Defines the description list.
  2. <dt> – Defines the term.
  3. <dd> – Gives the description of the term.
<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
</dl>
Easy way to remember: DL → Description List | DT → Description Term | DD → Description Details

e. What is the use of type attribute with an unordered list?

  • The type attribute is used to change the style of bullets in an unordered list.
  • Common values are: disc, circle, square.
<ul type="square">
    <li>Apple</li>
    <li>Mango</li>
</ul>

The items will appear with square bullets.

f. State the use of any two properties that you use to enhance the appearance of a table.

1. border

  • It adds a border around the table and its cells.
table {
    border: 2px solid black;
}

2. background-color

  • It adds a background colour to the table.
table {
    background-color: lightblue;
}

Other useful properties: padding, text-align, border-collapse, etc.

g. How are images added in an HTML document?

  • Images are added using the <img> tag.
  • The src attribute specifies the location of the image.
  • The alt attribute provides alternative text.
<img src="image.jpg" alt="Description of image">
Remember: <img> is an empty tag, so it does not need a closing tag.
