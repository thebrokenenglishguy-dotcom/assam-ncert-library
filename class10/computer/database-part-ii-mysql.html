I. Multiple Choice Questions

b) SELECT

III. Answer the Following Questions

1. Who were the developers of MySQL?

  1. Michael Widenius
  2. David Axmark
  3. Allan Larsson

They developed MySQL in Sweden.

2. Why is MySQL becoming so popular? Give two reasons.

  1. MySQL is open-source and freely available.
  2. It is fast, reliable and easy to use.

3. What is a constraint? Name any two constraints.

A constraint is a rule applied to a table to control the type of data that can be entered.

  1. PRIMARY KEY
  2. NOT NULL

Other examples include UNIQUE, DEFAULT, CHECK and FOREIGN KEY.

4. Give examples of DML commands.

INSERT, UPDATE and DELETE. These commands are used to add, change and remove data.

5. What are the characteristics by which you can determine the data type of MySQL?

  1. Type of data – number, text or date.
  2. Size of data – how much space the data needs.
  3. Range of values – minimum and maximum values that can be stored.

6. What is the query to display the table structure?

DESCRIBE table_name;

Example:

DESCRIBE customer;

7. What is the query to display all the records in a table?

SELECT * FROM table_name;

Example:

SELECT * FROM customer;

Here, * means all columns.

9. List the Relational Operators used in MySQL.

  • = → Equal to
  • > → Greater than
  • < → Less than
  • >= → Greater than or equal to
  • <= → Less than or equal to
  • <> or != → Not equal to

10. Differentiate between COUNT(*) and COUNT.

COUNT(*)COUNT(column)
Counts all rows in a table.Counts the non-NULL values in the specified column.
It includes rows even when some column values are NULL.NULL values in that column are not counted.
SELECT COUNT(*) FROM Worker;

This counts all records.

SELECT COUNT(Salary) FROM Worker;

This counts records having a non-NULL Salary.

11. What are the rules for naming a table in MySQL?

  1. A table name should generally begin with a letter.
  2. It should not contain spaces.
  3. It should not use reserved words.
  4. It should be meaningful and easy to understand.
  5. Special characters should generally be avoided.
  6. Table names should be unique within a database.

12. Explain the five categories of SQL commands.

1. DDL – Data Definition Language

Used to define or change the structure of a database.

Examples: CREATE, ALTER, DROP

2. DML – Data Manipulation Language

Used to add, modify and delete data.

Examples: INSERT, UPDATE, DELETE

3. DQL – Data Query Language

Used to retrieve data.

Example: SELECT

4. DCL – Data Control Language

Used to control access to data.

Examples: GRANT, REVOKE

5. TCL – Transaction Control Language

Used to manage database transactions.

Examples: COMMIT, ROLLBACK

DDL → Structure | DML → Data | DQL → Query | DCL → Control | TCL → Transaction
