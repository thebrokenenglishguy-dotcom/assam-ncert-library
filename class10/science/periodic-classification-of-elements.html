Chapter — Periodic Classification of Elements

Class X Science · Assam textbook

Questions inside the chapter

1. What was Döbereiner’s main idea in forming triads?
Answer: He grouped three similar elements so that the atomic mass of the middle element was approximately the average of the other two.
2. What was Newlands’ Law of Octaves?
Answer: When elements were arranged by increasing atomic mass, every eighth element had properties similar to the first, for the lighter elements.
3. Why was Mendeleev’s table important?
Answer: It arranged elements systematically and left gaps for undiscovered elements, predicting their properties.
4. What is the Modern Periodic Law?
Answer: The properties of elements are a periodic function of their atomic numbers.

End-of-chapter Exercises

1. Which statement is incorrect across a period from left to right?
Answer: The statement that atoms lose electrons more easily is incorrect; metallic character and ease of electron loss generally decrease.
2. X forms XCl₂ with high melting point. Which listed element is in the same group?
Answer: Magnesium, because Mg commonly forms MgCl₂ and is in group 2.
3. Identify elements from electronic configurations: two full shells; 2,8,2; three shells with four valence electrons; two shells with three valence electrons; second shell twice the first.
Answer: (a) Neon. (b) Magnesium. (c) Silicon. (d) Boron. (e) Carbon.
4. What common property is shared by elements in boron’s group and fluorine’s group?
Answer: Elements in a group have the same number of valence electrons and therefore similar chemical properties.
5. For configuration 2,8,7, find atomic number and a chemically similar element from N, F, P and Ar.
Answer: Atomic number 17; fluorine and chlorine are in the same group and have seven valence electrons.
6. For the shown positions of A, B and C in groups 16 and 17, identify A’s nature, compare C and A reactivity, compare C and B size, and state A’s ion.
Answer: A is a non-metal; C is less reactive than A down the group; C is smaller than B if C is below B in the same period/group arrangement; A tends to form an anion.
7. Compare nitrogen and phosphorus electronic configurations and electronegativity.
Answer: N: 2,5; P: 2,8,5. Nitrogen is more electronegative because its valence shell is closer to the nucleus.
8. How does electronic configuration determine position in the Modern Periodic Table?
Answer: The number of occupied shells gives the period, while valence electrons help determine the group for main-group elements.
9. Which elements around calcium (Z=20) resemble it most: 12,19,21,38?
Answer: Magnesium (12) and strontium (38), because they are in the same group as calcium.
10. Compare Mendeleev’s and Modern Periodic Tables.
Answer: Mendeleev used increasing atomic mass with chemical properties and had some anomalies/gaps. The Modern Table uses atomic number and has 18 groups and 7 periods.
