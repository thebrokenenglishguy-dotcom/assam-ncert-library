UNIT I — Introduction to Python Programming

Unit duration: 6 hours. These notes combine the Unit I syllabus you shared with the topics and examples in your 27-page PDF. The language is kept simple. The examples are for learning Python, not for making clinical decisions.

1. What is Python?

  • Python is a high-level, interpreted, general-purpose programming language.
  • High-level: its commands are easier for people to read than low-level machine instructions.
  • Interpreted: the Python interpreter runs the program; a separate compilation step is usually not needed.
  • General-purpose: Python can be used for many types of tasks.
  • Object-oriented: it supports classes and objects, along with inheritance, polymorphism and encapsulation.
  • Python was created by Guido van Rossum and first released in 1991.
  • The name came from the comedy show Monty Python's Flying Circus, not from the snake.
  • Python 3 is the modern version to use. Python 2 is no longer maintained.

2. Main characteristics, advantages and limitations

Characteristics and advantages:

  • Simple, readable syntax that is friendly to beginners.
  • Fast to test and debug because code can be run directly by the interpreter.
  • Works on Windows, macOS and Linux.
  • Free and open source.
  • Has a large community and many learning resources.
  • Includes a large standard library.
  • Supports reusable, object-oriented code and can work with other languages and tools.

Limitations:

  • It can run more slowly than compiled languages such as C or C++ for some tasks.
  • It may use more memory than some lower-level languages.
  • It is not the first choice for every mobile application.
  • It is less commonly used for very low-level hardware programming.

3. Applications of Python

  • Data analysis and visualisation: organise data and create graphs.
  • Web development: build websites and web services using tools such as Django and Flask.
  • Artificial intelligence and machine learning: analyse data and build predictive models.
  • Automation: perform repeated tasks such as file organisation and report generation.
  • Scientific computing: perform numerical calculations and simulations.

Uses in pharmaceutical sciences:

  • Pharmaceutical chemistry: analyse chemical structures and calculate molecular properties; tools such as RDKit can support cheminformatics and QSAR work.
  • Pharmaceutics: calculate ingredient quantities and formulation ratios for checking and research.
  • Pharmacology and toxicology: analyse concentration-response data and estimate values such as EC50 and IC50 using suitable methods.
  • Pharmacognosy: analyse biological sequences and genetic data using tools such as BioPython.
  • Pharmacy practice and clinical pharmacy: help analyse health datasets and identify records that may need professional review. Software output must not replace clinical judgement.

4. Installing Python and choosing an IDE

  • An IDE means Integrated Development Environment. It brings together tools to write, run and debug code.
  • Jupyter Notebook: runs code in separate cells; useful for learning, data analysis and showing results with notes.
  • PyCharm: a feature-rich environment suited to larger Python projects.
  • Visual Studio Code (VS Code): a flexible editor that can support Python through extensions and configuration.

Basic installation steps from the PDF:

  • Windows: download Python from python.org, run the installer, select “Add Python to PATH”, then install.
  • macOS: open the downloaded package and follow the installation steps.
  • Linux: check whether Python 3 is installed with python3 --version; use your distribution's package manager if needed.
  • Check installation in a terminal with python --version or python3 --version.
  • Install and open an IDE separately, then select the Python interpreter/environment you want to use.

Advantages of IDEs over a basic text editor:

  • Syntax highlighting makes code easier to read.
  • Code completion can suggest commands and names.
  • Error checking and debugging tools help locate problems.
  • Running code and managing project files is more convenient.
  • A basic text editor mainly edits text; programming features may need separate tools or setup.

5. Variables and naming rules

  • A variable is a name that refers to a value used by a program.
  • Python creates a variable when a value is assigned to it with =.
  • A name must start with a letter or underscore, not a number.
  • A name can contain letters, numbers and underscores.
  • Names are case-sensitive: Dose and dose are different.
  • Reserved words such as if, for and while cannot be used as variable names.
  • Use clear names such as drug_name and patient_age.
  • Valid examples: drug_concentration, patient_age, dose_mg. Invalid examples: 2dose, drug-name, for.
  • Python also supports multiple assignment, for example time, dose = 2, 500.
concentration = 25.5
drug_name = "Paracetamol"
time, dose = 2, 500

print(concentration)
print(drug_name)
print(time, dose)

6. The four basic data types

  • Integer (int): a whole number, such as 30. Example: number of tablets counted.
  • Float (float): a number with a decimal point, such as 15.42. Example: a measured concentration.
  • String (str): text inside quotes, such as "Paracetamol". Example: a medicine name.
  • Boolean (bool): either True or False. Example: whether a sample is available.
  • Use type() to check a value's type.
  • Floating-point numbers can have tiny rounding differences because computers store many decimal fractions approximately. For work needing exact decimal arithmetic, Python's decimal module may be more suitable.
tablets_dispensed = 30
plasma_concentration = 15.42
drug_name = "Paracetamol"
sample_available = True

print(type(tablets_dispensed))
print(type(plasma_concentration))
print(type(drug_name))
print(type(sample_available))

7. Type casting (type conversion)

  • Type casting means changing a value from one data type to another.
  • Implicit casting: Python converts a type automatically when appropriate. Example: 10 + 2.5 produces 12.5.
  • Explicit casting: the programmer converts the value using a function.
  • int(12.99) gives 12; it removes the decimal part and does not round to 13.
  • float("25.5") gives 25.5.
  • str(500) gives the text "500".
  • bool(0) is False; non-zero numbers are True. An empty string is False, while a non-empty string is True.
  • input() returns text, so convert it before numeric calculations.
result = 10 + 2.5
print(result)              # 12.5

print(int(12.99))          # 12
print(float("25.5"))       # 25.5
print(str(500))            # "500"
print(bool(""))            # False

dose_text = input("Enter a whole-number dose for this exercise: ")
dose = int(dose_text)
print(dose)

If the user enters text that cannot be converted to the requested number type, Python raises an error. Programs can later be improved by validating input and handling errors.

8. Basic operators

Arithmetic operators:

OperatorMeaningExampleResult
+Addition250 + 500750
-Subtraction100 - 2080
*Multiplication70 * 2140
/Division100 / 205.0
//Floor division7 // 23
%Remainder (modulus)7 % 21
**Power2 ** 38

Operator order: parentheses first, then powers, then multiplication/division/floor division/remainder, then addition/subtraction. Use parentheses to make calculations clear.

print(10 + 5 * 2)       # 20
print((10 + 5) * 2)     # 30
print(7 // 2, 7 % 2)    # 3 1

Comparison operators: these compare values and return True or False.

  • == equal to; != not equal to; > greater than; < less than; >= greater than or equal to; <= less than or equal to.
  • = assigns a value; == checks equality.
  • Chained comparisons are allowed, for example 10 < dose < 1000.

Logical operators:

  • and is true when both conditions are true.
  • or is true when at least one condition is true.
  • not reverses a Boolean value.
  • Order: not, then and, then or. Parentheses improve clarity.
  • Python uses short-circuit evaluation: with and, a false first condition can stop the check; with or, a true first condition can stop the check.
dose = 250
print(dose >= 100)                  # True
print(10 < dose < 1000)             # True
print((dose > 0) and (dose <= 1000)) # True
print(not False)                    # True

Common errors: using = instead of == in a comparison, comparing incompatible types, forgetting operator order, and dividing by zero.

9. Input and output operations

  • input() reads what a user types and returns it as a string.
  • print() displays text, variables and results.
  • Convert input with int() or float() when it is used in a calculation.
  • Use sep to choose the separator between printed values and end to choose what is printed at the end.
  • An f-string such as f"Dose: {dose} mg" inserts a variable into text. Formatting such as {value:.2f} displays two decimal places.
name = input("Enter sample name: ")
volume = float(input("Enter volume in mL: "))
print("Sample", name, sep=": ")
print(f"Volume: {volume:.2f} mL")
print("A", "B", sep=" - ")
print("Done", end="!\n")

10. Basic string operations and manipulation

  • A string is a sequence of characters written inside single or double quotes. Triple quotes can hold text across multiple lines.
  • Indexing: access one character. Indexing starts at 0; index -1 is the last character.
  • Slicing: extract part of a string using text[start:stop]; the stop index is not included. text[::-1] reverses a string.
  • Concatenation: join strings with +. Repetition: repeat text with *.
  • len(text) counts characters; upper() and lower() change letter case.
  • strip() removes spaces from the beginning and end; replace(old, new) replaces text.
  • split() separates text into a list; join() combines strings from an iterable using a separator.
  • find() returns the position of a substring or -1 if not found; count() counts occurrences.
  • isdigit() checks whether all characters are digits. in checks whether a substring is present. startswith() and endswith() check the beginning and end.
  • Strings are immutable: their characters cannot be changed in place. String methods return new strings.
drug = "Paracetamol"
print(drug[0])             # P
print(drug[-1])            # l
print(drug[0:4])           # Para
print(drug[::-1])          # lomatecaraP
print(len(drug))           # 11
print(drug.lower())
print(drug.upper())
print("  Drug A  ".strip())
print("Drug A".replace("A", "B"))
print("500,2.5".split(","))
print(" ".join(["Drug", "A"]))
print(drug.find("mol"))
print("123".isdigit())
print("para" in drug.lower())
print(drug.startswith("Para"))
print(drug.endswith("mol"))

Pharmacy-related use: string methods can clean extra spaces in medicine names, standardise upper/lower case, separate data fields and check labels. Always retain and protect source data when cleaning real records.

String-cleaning example:

dirty_name = "     ibuPROFEN   "
clean_name = dirty_name.strip()
print(clean_name)
print(clean_name.lower())
print(clean_name.upper())
print(len(clean_name))
print(clean_name.lower().count("profen"))
print(clean_name.replace("ibu", "acet"))
print(clean_name.startswith("ibu"))
print(clean_name.lower().endswith("fen"))

12. File handling (additional material in your PDF)

  • Python's open() function can read or write files.
  • "r" reads an existing file; "w" writes and replaces existing content; "a" adds content at the end.
  • Using with open(...) is recommended because it closes the file automatically.
with open("data.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Sample result: 25")

UNIT II — Control Structures and Functions
Q1. What is a conditional statement?

A conditional statement chooses which code to execute based on whether a condition is true or false. Python uses if, elif and else. Indentation is required to show which statements belong to each block.

stock = 8
if stock == 0:
    print("Out of stock")
elif stock < 10:
    print("Low stock")
else:
    print("Stock sufficient")
Q2. What is a nested condition?

A nested condition is an if statement placed inside another conditional block. It is useful when a second decision should be made only after the first condition is met.

Q3. Differentiate between a for loop and a while loop.

A for loop iterates over items in a sequence or range. A while loop repeats as long as its condition remains true. A while loop needs a condition that eventually becomes false to avoid running indefinitely.

for day in range(1, 4):
    print("Day", day)

count = 1
while count <= 3:
    print("Count", count)
    count += 1
Q4. Explain break and continue.

break ends the nearest loop immediately. continue skips the remaining statements in the current iteration and proceeds to the next iteration.

Q5. What is a function? Explain parameters and return values.

A function is a reusable block of code defined with def. Parameters receive values passed to the function. The return statement sends a result back to the calling code.

def calculate_total(price, quantity):
    return price * quantity

amount = calculate_total(12.5, 4)
print(amount)
Q6. What is a modular program?

A modular program is divided into smaller functions or modules, each handling a clear task. It is easier to test, maintain and reuse than one large block of code.

Q7. Write a program to calculate BMI.
weight_kg = float(input("Weight in kg: "))
height_m = float(input("Height in metres: "))

if height_m > 0:
    bmi = weight_kg / (height_m ** 2)
    print("BMI:", round(bmi, 2))
else:
    print("Height must be greater than zero")

BMI is calculated as weight in kilograms divided by height in metres squared. This code demonstrates a formula and input validation. BMI alone is not a diagnosis.

Q8. Write a program that demonstrates a dosage calculation using supplied educational values.
# Educational arithmetic example only
prescribed_amount_mg = float(input("Amount required in mg: "))
strength_mg_per_tablet = float(input("Strength per tablet in mg: "))

if prescribed_amount_mg >= 0 and strength_mg_per_tablet > 0:
    tablets = prescribed_amount_mg / strength_mg_per_tablet
    print("Calculated tablet-equivalent:", tablets)
else:
    print("Enter valid positive values")

The program divides the entered amount by the entered strength. It does not decide whether the amount is clinically appropriate or whether a tablet may be divided. Real dosing must be checked by a qualified professional.

UNIT III — Data Structures and File Handling
Q1. What are lists, tuples and dictionaries?

A list is an ordered, changeable collection, written with square brackets. A tuple is an ordered, unchangeable collection, written with parentheses. A dictionary stores key-value pairs, written with braces.

readings = [4.1, 4.3, 4.2]
fixed_values = (10, 20, 30)
sample = {"id": "S01", "pH": 7.0}

readings.append(4.4)
print(readings[0])
print(sample["pH"])
Q2. Explain indexing and slicing.

Indexing accesses one item by its position; Python sequence indexing starts at 0. Slicing extracts a portion using sequence[start:stop:step]; the stop position is not included. Negative indexes count from the end.

values = [10, 20, 30, 40, 50]
print(values[0])     # 10
print(values[1:4])   # [20, 30, 40]
print(values[-1])    # 50
Q3. Give examples of list and dictionary operations.

Lists support operations such as append(), remove(), sort() and len(). Dictionaries support adding or updating a value by key, retrieving values with get(), and checking their keys.

Q4. What is NumPy?

NumPy is a third-party Python library for numerical computing. Its main array structure supports efficient operations on collections of numbers. Install it with python -m pip install numpy.

import numpy as np

concentrations = np.array([2.0, 4.0, 6.0])
doubled = concentrations * 2
average = np.mean(concentrations)
print(doubled)
print(average)
Q5. What is a CSV file? How can Python read one?

CSV means comma-separated values. It is a text format commonly used to store rows and columns. Python's built-in csv module can read and write CSV files.

import csv

with open("samples.csv", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row)
Q6. What is a structured healthcare dataset?

It is data organised in a consistent format, often as rows and columns. For example, a teaching dataset might have columns for sample ID, test date, measured concentration and result. Identifying information should be removed or protected, and access should follow applicable privacy rules.

Q7. Write a small program to access and manipulate a dataset.
samples = [
    {"id": "A01", "concentration": 2.1},
    {"id": "A02", "concentration": 3.4},
    {"id": "A03", "concentration": 1.8}
]

for sample in samples:
    if sample["concentration"] > 2.0:
        print(sample["id"], sample["concentration"])

The program loops through a list of dictionaries and prints only records whose concentration is greater than 2.0. The threshold is only a programming example, not a clinical cut-off.

Q8. How can a CSV file be written?
import csv

rows = [
    {"sample_id": "A01", "result": 2.1},
    {"sample_id": "A02", "result": 3.4}
]

with open("results.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.DictWriter(file, fieldnames=["sample_id", "result"])
    writer.writeheader()
    writer.writerows(rows)

The program opens a CSV file in write mode, writes column headings, then writes each dictionary as a row.

UNIT IV — Data Handling with Pandas
Q1. What is pandas?

Pandas is a Python library used to work with tabular data. It helps read data files, inspect columns, filter rows, handle missing values and calculate summaries. Install it with python -m pip install pandas.

Q2. What is a Series? What is a DataFrame?

A Series is a one-dimensional labelled data structure. A DataFrame is a two-dimensional table with rows and columns. A DataFrame is useful for data such as a list of study samples with dates, measured values and result categories.

import pandas as pd

data = {
    "sample_id": ["A01", "A02", "A03"],
    "concentration": [2.1, 3.4, 1.8]
}
df = pd.DataFrame(data)
print(df)
Q3. How do you read CSV and Excel files?

Use pd.read_csv("file.csv") for a CSV file and pd.read_excel("file.xlsx") for an Excel file. Excel support may require an additional engine package such as openpyxl to be installed.

Q4. Explain head(), tail(), info() and describe().

head() shows the first rows; tail() shows the last rows; info() summarises column names, data types and non-missing counts; and describe() gives summary statistics for suitable columns.

print(df.head())
print(df.tail())
df.info()
print(df.describe())
Q5. What is data cleaning?

Data cleaning means identifying and correcting problems such as missing values, duplicate records, inconsistent labels, wrong data types and impossible values. Keep an unchanged source copy and document important cleaning steps.

Q6. How can missing values be inspected and handled?

Use df.isna().sum() to count missing values. Depending on the reason for missingness, one may remove incomplete rows with dropna() or fill selected values with fillna(). Do not automatically replace missing scientific or clinical values with zero; that can mislead analysis.

print(df.isna().sum())
df_without_missing = df.dropna(subset=["concentration"])
# Only if justified by the data and analysis plan:
# df["concentration"] = df["concentration"].fillna(df["concentration"].median())
Q7. How do you filter and select data?

Select a column with df["column_name"]. Filter rows with a Boolean condition, for example df[df["concentration"] > 2]. Check that the condition and units match the purpose of the analysis.

Q8. What are grouping and aggregation?

Grouping divides rows into categories, and aggregation calculates summaries for each category. Examples include mean concentration by batch or number of reports by drug name.

summary = df.groupby("batch")["concentration"].mean()
print(summary)
Q9. What are PK study datasets and ADR reports?

PK means pharmacokinetics, the study of how drug concentration changes in the body over time. An ADR is an adverse drug reaction. Educational datasets may be used to practise organising concentration-time observations or summarising adverse-event reports. Such analysis alone does not prove that a medicine caused an event.

UNIT V — Data Visualization with Matplotlib
Q1. What is Matplotlib?

Matplotlib is a Python plotting library used to create graphs. It can display trends, distributions, relationships and differences in datasets. Install it with python -m pip install matplotlib.

Q2. Explain line plots, histograms, scatter plots and box plots.

A line plot shows how values change across an ordered sequence, such as time. A histogram shows the distribution of a numeric variable. A scatter plot shows the relationship between two numeric variables. A box plot summarises a distribution using the median, quartiles and potential outliers.

Q3. Write a program to make a line plot.
import matplotlib.pyplot as plt

time_hours = [0, 1, 2, 4, 6]
concentration = [0, 3.2, 5.1, 3.0, 1.2]

plt.plot(time_hours, concentration, marker="o", label="Sample")
plt.xlabel("Time (hours)")
plt.ylabel("Concentration (example units)")
plt.title("Example Concentration-Time Curve")
plt.legend()
plt.tight_layout()
plt.show()

The x-axis represents time and the y-axis represents concentration. These illustrative values are not real patient data or a dosing recommendation.

Q4. How do you label axes, add a title and display a legend?

Use xlabel() for the horizontal axis, ylabel() for the vertical axis, title() for the plot title and legend() to identify labelled data series. Include units where relevant.

Q5. Write code to create a histogram and a scatter plot.
import matplotlib.pyplot as plt

measurements = [1.8, 2.0, 2.1, 2.1, 2.4, 2.8, 3.0]
plt.hist(measurements, bins=5, edgecolor="black")
plt.xlabel("Measurement (example units)")
plt.ylabel("Frequency")
plt.title("Distribution of Measurements")
plt.show()

time = [1, 2, 3, 4, 5]
response = [2.0, 2.7, 3.1, 3.8, 4.2]
plt.scatter(time, response)
plt.xlabel("Time (example units)")
plt.ylabel("Response (example units)")
plt.title("Time and Response")
plt.show()
Q6. How can graphs be used for pharmaceutical datasets?

Line plots can display concentration-time curves after oral or IV administration. Histograms can show the distribution of measurements. Bar charts can compare counts or reporting rates across categories. Dissolution profiles can show the percentage dissolved over time. Plot selection should match the question being studied.

Q7. What should be considered when scientifically interpreting a plot?

Check axis labels and units, the scale, sample size, missing data, variability, outliers and the data source. Describe the pattern shown without claiming more than the data supports. A graph can suggest an association but does not by itself prove causation.

Q8. What is an adverse drug reaction reporting rate graph?

It is a visual summary of reported adverse drug reactions across selected categories or time periods. The denominator, time window and definition of the rate must be clear. A larger number of reports does not automatically mean a drug has a higher true risk, because reporting and exposure can differ.
